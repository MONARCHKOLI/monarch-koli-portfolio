# Monarch Koli Portfolio

A recruiter-focused, dark premium portfolio website for Monarch Koli, built with static HTML and Tailwind CSS.

## Local preview

Open the project folder in a browser or run a local server:

```bash
cd portfolio
python -m http.server 8000
```

Then visit:

- http://localhost:8000

## Deployment

This project is ready to be published using GitHub Pages by pushing the files to a repository and enabling Pages from the repository settings.

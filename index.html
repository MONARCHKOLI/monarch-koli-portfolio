BugSage Gem

Author & Creator · Latest Stable Version: 0.2.0

GitHub RubyGems

BugSage is an architectural debugging extension gem for Rails that catches development and test exceptions, runs deterministic rule-based classification, extracts request context, and presents an interactive UI panel for faster remediation.

  • Zero-config hooking: custom Rails Railties integrate without extra setup.
  • Surgical patching: supports replace_lines, insert_before, and delete_lines.
  • Interactive dashboard: mounted at /bugsage for runtime issue analysis.
  • AI repair panel: integrates with OpenAI and Cursor Cloud Agents for on-demand code repair support.
